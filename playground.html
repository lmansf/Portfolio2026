Owl Park is a made-up park and every row here is synthetic: no names, emails, or card details, real or simulated. Attendance follows season, weekends, holidays, heat, and rain; about one checkout in a hundred is fraud, and each order carries a synthetic risk score shaped like the one my fraud detection pipeline produces. The data comes from a seeded Python script. Queries run on your device against a read-only copy, with no network or file access; reload the page to start fresh.
