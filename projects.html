Data engineering

2026

Fraud Detection Pipeline

A scheduled Databricks job simulates an hour of Owl Park webstore checkouts, normal guests plus five kinds of fraud episode (card testing, stolen-card resale, gift-card cash-out, account takeover, fraud rings), scores every order with a rules model, simulates the issuer’s response with a fail-open timeout, and writes four raw tables to Supabase in one transaction. Ground-truth labels arrive days later, like a chargeback. A daily dashboard tracks catch rate, false positives, decline rate, and fail-open exposure.

  • Databricks
  • Python
  • Supabase / Postgres
  • SQL

Owl Park

A virtual owl park you visit online. Every visitor is an owl: tap to walk through 2D rooms and see everyone else there in real time. 2026

Lighthouse v0.15

A local-first desktop app that answers questions about a small group of files, with citations back to the passages it read. A Rust engine in a Tauri 2 shell handles extraction, on-device OCR and embeddings, and hybrid retrieval. A question over a spreadsheet becomes one read-only SQL query, run by DataFusion and shown verbatim. Use the bundled private model or bring your own key. Installers for Windows, macOS, and Linux.

Browser app · LLM + SQL

2026

Quack Query Live

Ask a data file questions in plain English. CSV, Excel, Parquet, or JSON files load into DuckDB running as WebAssembly in the browser, so files never leave it; a serverless function has an LLM write one read-only SQL query from automatic table profiles and join-key hints, validated on both server and client and run locally. The public endpoint is hardened with a request guard, per-IP rate limiting, a locked-down engine, a content security policy, and personal-data columns withheld from the model.

  • DuckDB-Wasm
  • TypeScript
  • Vercel
  • LLM APIs

Forecasting · Machine learning

2026

Attendance Forecasting

Daily theme-park attendance forecast from weather, calendar, and flight-traffic features. A LightGBM, ridge, and random-forest blend selected by rolling-origin cross-validation beat a tuned XGBoost by about 6% MAE out of fold and cut mean bias from +90 to −7 guests a day. The last 30 operating days are held out as an unseen live forecast with an 80% planning band from pooled out-of-fold ratios.

USL Attendance Forecasting

An XGBoost demand model on nine seasons of USL Championship matches, on a staged DuckDB warehouse (raw → staging → marts). Two models share every upstream table and differ only by league-position features, so the error gap measures what promotion and relegation will do to attendance from 2028. Tableau views on top.
